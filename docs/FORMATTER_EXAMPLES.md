# ST formatter: an example for every rule

Generated by `TcAgent.exe format --examples --markdown` - the formatter made every result below, so they show what it
really does. Each example changes only the rule it is about; all other rules leave the code alone (profile `preserve`).
The rules, their defaults and the configuration: [FORMATTER.md](FORMATTER.md).

## Indentation

### Indent with (`indent.style`)

Indent with spaces or tabs. Default: `spaces`.

Written as:

```
IF a THEN
  b := 1;
END_IF
```

`spaces`:

```
IF a THEN
  b := 1;
END_IF
```

`tabs`:

```
IF a THEN
	b := 1;
END_IF
```

### Spaces per level (`indent.size`)

Spaces per level (with tabs: one tab per level). Default: `2`.

Written as:

```
IF a THEN
  IF b THEN
    c := 1;
  END_IF
END_IF
```

`2`:

```
IF a THEN
  IF b THEN
    c := 1;
  END_IF
END_IF
```

`4`:

```
IF a THEN
    IF b THEN
        c := 1;
    END_IF
END_IF
```

### CASE labels one level in (`indent.case-labels`)

CASE labels one level under CASE, their statements one more. Default: `true`.

Written as:

```
CASE eState OF
E_State.Idle:
x := 1;
E_State.Run:
x := 2;
END_CASE
```

`true`:

```
CASE eState OF
  E_State.Idle:
    x := 1;
  E_State.Run:
    x := 2;
END_CASE
```

`false`:

```
CASE eState OF
E_State.Idle:
  x := 1;
E_State.Run:
  x := 2;
END_CASE
```

### Names with _ one column left (`indent.underscore`)

A name that starts with _ one column further left, so its letters line up with the other names. Default: `off`; shown with `align.decl: true`.

Written as:

```
VAR
  bStart : BOOL;
  _localCount : INT;
  nParts : INT;
END_VAR
```

`off`:

```
VAR
  bStart      : BOOL;
  _localCount : INT;
  nParts      : INT;
END_VAR
```

`declarations`:

```
VAR
  bStart     : BOOL;
 _localCount : INT;
  nParts     : INT;
END_VAR
```

`everywhere`:

```
VAR
  bStart     : BOOL;
 _localCount : INT;
  nParts     : INT;
END_VAR
```

### Continuation lines (`indent.continuation`)

Continuation lines: keep their offset to the first line, or one level. Default: `preserve`.

Written as:

```
nSum := nFirst +
          nSecond;
```

`preserve`:

```
nSum := nFirst +
          nSecond;
```

`indent`:

```
nSum := nFirst +
  nSecond;
```

## Spaces

### Around operators (`space.operators`)

One space around :=, =>, S=, R=, REF=, + - * /, comparisons, AND/OR. Default: `one`.

Written as:

```
nX:=nA+nB*2;
bHigh:=nX>=10;
```

`one`:

```
nX := nA + nB * 2;
bHigh := nX >= 10;
```

`preserve`:

```
nX:=nA+nB*2;
bHigh:=nX>=10;
```

### After commas (`space.comma`)

No space before a comma, one after. Default: `one`.

Written as:

```
F_Sum(nA,nB ,nC);
```

`one`:

```
F_Sum(nA, nB, nC);
```

`preserve`:

```
F_Sum(nA,nB ,nC);
```

### Around the : of declarations (`space.decl-colon`)

One space around the : of a declaration. Default: `one`.

Written as:

```
VAR
  nCount:INT;
END_VAR
```

`one`:

```
VAR
  nCount : INT;
END_VAR
```

`preserve`:

```
VAR
  nCount:INT;
END_VAR
```

### Tabs inside a line (`space.tabs`)

A tab inside a line becomes spaces up to the next tab stop (indent.tab-width), the text keeps its column. Default: `replace`.

Written as:

```
nA := 1;	// first
nB := 22;	// second
```

`replace`:

```
nA := 1;    // first
nB := 22;   // second
```

`preserve`:

```
nA := 1;	// first
nB := 22;	// second
```

### Inside brackets (`space.parens`)

Spaces inside ( ) and [ ]. Default: `preserve`.

Written as:

```
nX := ( nA + nB ) * (nC);
```

`none`:

```
nX := (nA + nB) * (nC);
```

`one`:

```
nX := ( nA + nB ) * ( nC );
```

`preserve`:

```
nX := ( nA + nB ) * (nC);
```

### Keyword and ( (`space.keyword-paren`)

IF (, AND (, NOT (. Default: `one`.

Written as:

```
bX := NOT(bA) AND(bB);
```

`one`:

```
bX := NOT (bA) AND (bB);
```

`preserve`:

```
bX := NOT(bA) AND(bB);
```

### Name and ( (`space.call-paren`)

No space between a name and its (. Default: `none`.

Written as:

```
F_Sum (nA, nB);
```

`none`:

```
F_Sum(nA, nB);
```

`preserve`:

```
F_Sum (nA, nB);
```

## Layout

### One statement per line (`layout.blocks`)

One statement per line; the bodies of IF, CASE, FOR, WHILE and REPEAT on their own lines. Default: `preserve`.

Written as:

```
IF bStart THEN nCount := 0; bBusy := TRUE; END_IF
```

`expand`:

```
IF bStart THEN
  nCount := 0;
  bBusy := TRUE;
END_IF
```

`preserve`:

```
IF bStart THEN nCount := 0; bBusy := TRUE; END_IF
```

### THEN, DO, OF (`layout.then`)

THEN, DO and OF at the end of the condition or on their own line. Default: `preserve`.

Written as:

```
IF bStart THEN
  bBusy := TRUE;
END_IF
WHILE nIndex < 10
DO
  nIndex := nIndex + 1;
END_WHILE
```

`same-line`:

```
IF bStart THEN
  bBusy := TRUE;
END_IF
WHILE nIndex < 10 DO
  nIndex := nIndex + 1;
END_WHILE
```

`own-line`:

```
IF bStart
THEN
  bBusy := TRUE;
END_IF
WHILE nIndex < 10
DO
  nIndex := nIndex + 1;
END_WHILE
```

`preserve`:

```
IF bStart THEN
  bBusy := TRUE;
END_IF
WHILE nIndex < 10
DO
  nIndex := nIndex + 1;
END_WHILE
```

## Long lines

### Longest line (`wrap.max-length`)

Longest line; 0 = never wrap. Default: `120`; shown with `wrap.call-args: when-long`.

Written as:

```
fbAxis(Execute := bStart, Position := rTarget, Velocity := rSpeed, Acceleration := rAcc);
```

`0`:

```
fbAxis(Execute := bStart, Position := rTarget, Velocity := rSpeed, Acceleration := rAcc);
```

`60`:

```
fbAxis(
  Execute := bStart,
  Position := rTarget,
  Velocity := rSpeed,
  Acceleration := rAcc
);
```

### Long calls (`wrap.call-args`)

A call too long: one parameter per line, ) on its own line. Default: `when-long`; shown with `wrap.max-length: 60`.

Written as:

```
fbAxis(Execute := bStart, Position := rTarget, Velocity := rSpeed, Acceleration := rAcc);
```

`when-long`:

```
fbAxis(
  Execute := bStart,
  Position := rTarget,
  Velocity := rSpeed,
  Acceleration := rAcc
);
```

`never`:

```
fbAxis(Execute := bStart, Position := rTarget, Velocity := rSpeed, Acceleration := rAcc);
```

### Long conditions (`wrap.conditions`)

A condition or boolean assignment too long: one term per line at the weakest AND/OR. Default: `when-long`; shown with `wrap.max-length: 60`.

Written as:

```
IF bStartButton AND bDoorClosed AND NOT bEmergencyStop OR bSetupMode AND bKeySwitch THEN
  x := 1;
END_IF
```

`when-long`:

```
IF bStartButton AND bDoorClosed AND NOT bEmergencyStop
  OR bSetupMode AND bKeySwitch THEN
  x := 1;
END_IF
```

`never`:

```
IF bStartButton AND bDoorClosed AND NOT bEmergencyStop OR bSetupMode AND bKeySwitch THEN
  x := 1;
END_IF
```

### AND / OR stand (`wrap.operator`)

Where AND/OR stand when a condition is wrapped. Default: `first`; shown with `wrap.max-length: 60`, `wrap.conditions: when-long`.

Written as:

```
IF bStartButton AND bDoorClosed AND NOT bEmergencyStop OR bSetupMode AND bKeySwitch THEN
  x := 1;
END_IF
```

`first`:

```
IF bStartButton AND bDoorClosed AND NOT bEmergencyStop
  OR bSetupMode AND bKeySwitch THEN
  x := 1;
END_IF
```

`last`:

```
IF bStartButton AND bDoorClosed AND NOT bEmergencyStop OR
   bSetupMode AND bKeySwitch THEN
  x := 1;
END_IF
```


Blank lines at the start and end of a part. Default: `remove`.

Written as:


`preserve`:

```

```

### Blank lines around blocks (`blank.around-blocks`)

A blank line before and after IF, CASE, FOR, WHILE and REPEAT blocks. Default: `preserve`.

```
  nB := 2;
```


`preserve`:

```
nA := 1;
IF bStart THEN
  nB := 2;
END_IF

```

## Brackets in conditions

### Brackets for AND in OR (`paren.precedence`)

Brackets around AND groups inside OR, so the order is visible (the meaning stays). Default: `true`.

Written as:

```
bRelease := bAuto AND bDoorClosed OR bSetup AND bKey;
```

`true`:

```
bRelease := (bAuto AND bDoorClosed) OR (bSetup AND bKey);
```

`false`:

```
bRelease := bAuto AND bDoorClosed OR bSetup AND bKey;
```
