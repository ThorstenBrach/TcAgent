# ST formatter: an example for every rule

Generated by `TcAgent.exe format --examples --markdown` - the formatter made every result below, so they show what it
really does. Each example changes only the rule it is about; all other rules leave the code alone (profile `preserve`).
The rules, their defaults and the configuration: [FORMATTER.md](FORMATTER.md).

## Indentation

### Indent with (`indent.style`)

Indent with spaces or tabs. Default: `spaces`.

Written as:

```
IF a THEN
  b := 1;
END_IF
```

`spaces`:

```
IF a THEN
  b := 1;
END_IF
```

`tabs`:

```
IF a THEN
	b := 1;
END_IF
```

### Spaces per level (`indent.size`)

Spaces per level (with tabs: one tab per level). Default: `2`.

Written as:

```
IF a THEN
  IF b THEN
    c := 1;
  END_IF
END_IF
```

`2`:

```
IF a THEN
  IF b THEN
    c := 1;
  END_IF
END_IF
```

`4`:

```
IF a THEN
    IF b THEN
        c := 1;
    END_IF
END_IF
```

### CASE labels one level in (`indent.case-labels`)

CASE labels one level under CASE, their statements one more. Default: `true`.

Written as:

```
CASE eState OF
E_State.Idle:
x := 1;
E_State.Run:
x := 2;
END_CASE
```

`true`:

```
CASE eState OF
  E_State.Idle:
    x := 1;
  E_State.Run:
    x := 2;
END_CASE
```

`false`:

```
CASE eState OF
E_State.Idle:
  x := 1;
E_State.Run:
  x := 2;
END_CASE
```

### Names with _ one column left (`indent.underscore`)

A name that starts with _ one column further left, so its letters line up with the other names. Default: `off`; shown with `align.decl: true`.

Written as:

```
VAR
  bStart : BOOL;
  _localCount : INT;
  nParts : INT;
END_VAR
```

`off`:

```
VAR
  bStart      : BOOL;
  _localCount : INT;
  nParts      : INT;
END_VAR
```

`declarations`:

```
VAR
  bStart     : BOOL;
 _localCount : INT;
  nParts     : INT;
END_VAR
```

`everywhere`:

```
VAR
  bStart     : BOOL;
 _localCount : INT;
  nParts     : INT;
END_VAR
```

### Continuation lines (`indent.continuation`)

Continuation lines: keep their offset to the first line, or one level. Default: `preserve`.

Written as:

```
nSum := nFirst +
          nSecond;
```

`preserve`:

```
nSum := nFirst +
          nSecond;
```

`indent`:

```
nSum := nFirst +
  nSecond;
```

### Comment above CASE labels (`comment.case-labels`)

A comment above each CASE label that has none: the comment of the enum value, otherwise its name. Default: `off`.

Written as:

```
CASE eState OF
  E_State.Idle:
    IF bStart THEN eState := E_State.Run; END_IF
  E_State.Run:
    nCount := nCount + 1;
  E_State.Error:
    bAlarm := TRUE;
END_CASE
```

`off`:

```
CASE eState OF
  E_State.Idle:
    IF bStart THEN eState := E_State.Run; END_IF
  E_State.Run:
    nCount := nCount + 1;
  E_State.Error:
    bAlarm := TRUE;
END_CASE
```

`enum`:

```
CASE eState OF
  // waiting for start
  E_State.Idle:
    IF bStart THEN eState := E_State.Run; END_IF
  // the cycle runs
  E_State.Run:
    nCount := nCount + 1;
  // Error
  E_State.Error:
    bAlarm := TRUE;
END_CASE
```

## Layout

### One statement per line (`layout.blocks`)

One statement per line; the bodies of IF, CASE, FOR, WHILE and REPEAT on their own lines. Default: `preserve`.

Written as:

```
IF bStart THEN nCount := 0; bBusy := TRUE; END_IF
```

`expand`:

```
IF bStart THEN
  nCount := 0;
  bBusy := TRUE;
END_IF
```

`preserve`:

```
IF bStart THEN nCount := 0; bBusy := TRUE; END_IF
```

### Short IF on one line up to (`layout.short-if`)

IF ... THEN with one statement and END_IF on one line when it stays within this many characters. Default: `preserve`.

Written as:

```
IF bReset THEN
  nCount := 0;
END_IF
IF bStartConditionsComplete THEN
  eState := E_State.Run;
END_IF
```

`preserve`:

```
IF bReset THEN
  nCount := 0;
END_IF
IF bStartConditionsComplete THEN
  eState := E_State.Run;
END_IF
```

`40`:

```
IF bReset THEN nCount := 0; END_IF
IF bStartConditionsComplete THEN
  eState := E_State.Run;
END_IF
```

`80`:

```
IF bReset THEN nCount := 0; END_IF
IF bStartConditionsComplete THEN eState := E_State.Run; END_IF
```

### Longer IF on one line (`layout.long-if`)

An IF ... END_IF on one line that is longer than layout.short-if (or wrap.max-length): one statement per line. Default: `preserve`; shown with `layout.short-if: 40`.

Written as:

```
IF bReset THEN nCount := 0; END_IF
IF bStartConditionsComplete THEN eState := E_State.Run; nCount := 0; END_IF;
```

`expand`:

```
IF bReset THEN nCount := 0; END_IF
IF bStartConditionsComplete THEN
  eState := E_State.Run;
  nCount := 0;
END_IF;
```

`preserve`:

```
IF bReset THEN nCount := 0; END_IF
IF bStartConditionsComplete THEN eState := E_State.Run; nCount := 0; END_IF;
```

### THEN, DO, OF (`layout.then`)

THEN, DO and OF at the end of the condition or on their own line. Default: `preserve`.

Written as:

```

  bBusy := TRUE;
END_IF

  nIndex := nIndex + 1;
END_WHILE

`same-line`:

```

  bBusy := TRUE;
END_IF
WHILE nIndex < 10 DO
  nIndex := nIndex + 1;
END_WHILE
```

`own-line`:

```
IF bStart
THEN
  bBusy := TRUE;
END_IF
WHILE nIndex < 10
DO
  nIndex := nIndex + 1;
END_WHILE
```

```

  bBusy := TRUE;
END_IF

DO
  nIndex := nIndex + 1;
END_WHILE

Longest line; 0 = never wrap. Default: `120`; shown with `wrap.call-args: when-long`.

Written as:

```

```

`0`:

```

```

```
fbAxis(
  Execute := bStart,
  Position := rTarget,
  Velocity := rSpeed,
  Acceleration := rAcc
);
```

### Long calls (`wrap.call-args`)

A call too long: one parameter per line, ) on its own line. Default: `when-long`; shown with `wrap.max-length: 60`.

Written as:

```
fbAxis(Execute := bStart, Position := rTarget, Velocity := rSpeed, Acceleration := rAcc);
```

`when-long`:

```

  Execute := bStart,
  Position := rTarget,
  Velocity := rSpeed,
  Acceleration := rAcc
);
```

`never`:

```
fbAxis(Execute := bStart, Position := rTarget, Velocity := rSpeed, Acceleration := rAcc);
```

### Long conditions (`wrap.conditions`)

A condition or boolean assignment too long: one term per line at the weakest AND/OR. Default: `when-long`; shown with `wrap.max-length: 60`.

Written as:

```

  x := 1;
END_IF
```

`when-long`:

```
IF bStartButton AND bDoorClosed AND NOT bEmergencyStop
  OR bSetupMode AND bKeySwitch THEN
  x := 1;
END_IF
```

`never`:

```
IF bStartButton AND bDoorClosed AND NOT bEmergencyStop OR bSetupMode AND bKeySwitch THEN
  x := 1;
END_IF
```

### AND / OR stand (`wrap.operator`)

Where AND/OR stand when a condition is wrapped. Default: `first`; shown with `wrap.max-length: 60`, `wrap.conditions: when-long`.

Written as:

```
IF bStartButton AND bDoorClosed AND NOT bEmergencyStop OR bSetupMode AND bKeySwitch THEN
  x := 1;
END_IF
```

`first`:

```
IF bStartButton AND bDoorClosed AND NOT bEmergencyStop
  OR bSetupMode AND bKeySwitch THEN
  x := 1;
END_IF
```

`last`:

```
IF bStartButton AND bDoorClosed AND NOT bEmergencyStop OR
   bSetupMode AND bKeySwitch THEN
  x := 1;
END_IF

## cond

### One sub-condition per line (`cond.lines`)

Conditions after IF, ELSIF, WHILE, UNTIL: one sub-condition per line - always, only when too long, or as written (then the other cond rules do nothing). Default: `preserve`; shown with `layout.then: own-line`, `cond.paren-terms: always`, `cond.paren-groups: outer`, `cond.group-space: tight`, `cond.not: inside`, `cond.not-align: true`, `cond.operator: last`, `cond.continuation: paren`, `cond.nest-indent: indent`, `cond.align-close: true`, `cond.align-compare: true`, `cond.keyword-paren: one`, `cond.comments: align`, `wrap.max-length: 100`.

Written as:

```
IF bAuto AND NOT bError AND nPressure >= nMin OR bSetup AND bKey THEN
  x := 1;
END_IF
```

`per-term`:

```
IF (((     bAuto             ) AND
     ( NOT bError            ) AND
     (     nPressure >= nMin )) OR
    ((     bSetup            ) AND
     (     bKey              )))
THEN
  x := 1;
END_IF
```

`when-long`:

```
IF ((( bAuto ) AND ( NOT bError ) AND ( nPressure >= nMin )) OR (( bSetup ) AND ( bKey )))
THEN
  x := 1;
END_IF
```

`preserve`:

```
IF bAuto AND NOT bError AND nPressure >= nMin OR bSetup AND bKey
THEN
  x := 1;
END_IF
```

### Brackets around sub-conditions (`cond.paren-terms`)

Every sub-condition in its own brackets - always (also a single one), only when there are several, or as written. Default: `preserve`; shown with `layout.then: own-line`, `cond.lines: per-term`, `cond.group-space: tight`, `cond.not: inside`, `cond.not-align: true`, `cond.operator: last`, `cond.continuation: paren`, `cond.nest-indent: indent`, `cond.align-close: true`, `cond.align-compare: true`, `cond.keyword-paren: one`, `cond.comments: align`, `cond.paren-groups: or-groups`.

Written as:

  x := 1;

  x := 1;
END_IF

   bB

  x := 2;
END_IF
```
